# Изменения

## 0.5.0

Первая публикация в VS Code Marketplace и Open VSX.

- Нативы для `amxx.call`: автодополнение по встроенному индексу (AMX Mod X 1.10 и ReAPI, ~1400 нативов)
  и `.inc` проекта, документация при наведении, подсказка параметров, готовый вызов из Python.
- Заготовки по «@» в начале строки: команды, обработчики событий, нативы, задачи, пункты меню.
- def после Enter на строке декоратора и автоимпорт `Player`, `events`, `Access`.
- Палитра для `color=(r, g, b)` у HUD, полное имя cvar'а в строке, предпросмотр цветного чата и меню.
- Кнопки «Установить на сервер» и «Плагины на сервере» над `Plugin(...)`, ошибки amxpyc в «Проблемах».
