# Диагностики amxpyc

Компилятор проверяет плагин по исходному коду, ничего не запуская. **Ошибки** останавливают
сборку, **предупреждения** — нет (кроме `amxpy build --werror`). Те же коды показывает
VS Code при сохранении файла — через Flake8 с плагином amxpy.

Таблица собрана из кода компилятора; `…` — подставляемая часть сообщения.
