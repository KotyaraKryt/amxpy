# MVP раунда

Плагин считает убийства и хедшоты каждого игрока за раунд, а в конце объявляет лучшего
крупным HUD и даёт ему денежный бонус.

## Как это работает

- **`PlayerState(int)`** — счётчики по игрокам: значение по умолчанию 0, записи вышедших
  игроков удаляются сами.
- **`RoundStart`** обнуляет счётчики, **`PlayerKilled`** (post) считает только состоявшиеся
  убийства, **`RoundEnd`** (post) выбирает лучшего: больше убийств, при равенстве — больше
  хедшотов.
- **`DirectorHud`** — крупный текст всем игрокам; цвет — лаймовый `(198, 244, 50)`.

## Что проверяют тесты

- Alice убивает двоих (одного в голову) — DHUD «MVP раунда: Alice — 2 убийств, 1 в голову»,
  она получает $500, остальные — ничего;
- раунд без убийств ничего не объявляет.
