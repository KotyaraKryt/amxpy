# Привет и /hp

Четыре приёма в одном файле: async-приветствие, чат-команда, админ-команда с аргументами и
отмена урона по своим под управлением cvar'а.

```python title="examples/plugins/hello.py"
--8<-- "hello.py"
```

## Как это работает

- **`greet`** — async-обработчик `PutInServer`. Игрок сохраняется в переменную до `await`:
  объект события после него недействителен. Если игрок выйдет за время ожидания, задача
  отменится сама.
- **`no_team_damage`** — pre-обработчик `TakeDamage`: `e.cancel()` отменяет урон, если
  атакующий из той же команды, а `hello_friendly_fire` выключен.
- **`hp`** — чат-команда `/hp`; сообщение с командой в чате не показывается.
- **`heal`** — консольная команда с флагом доступа `e` (`Access.SLAY`). Аргументы `target` и
  `amount` amxpy разбирает сам: `amx_heal Bob 50`.

## Что проверяют тесты

- приветствие приходит через 3 секунды и отменяется, если игрок вышел;
- `/hp` скрывает сообщение и отвечает здоровьем и бронёй;
- урон по своим блокируется, по чужим и по себе — нет; cvar `hello_friendly_fire` это меняет;
- `amx_heal` без доступа отвечает «У вас нет доступа к этой команде.»
