# С возвращением

Плагин помнит игроков по SteamID: новичка приветствует, вернувшемуся пишет номер визита и дату
прошлого захода. Данные хранятся в SQLite.

```python title="examples/plugins/welcome_back.py"
--8<-- "welcome_back.py"
```

## Как это работает

- **`Table`** хранит dataclass `Visit` в `addons/amxpy/data/welcome_back.db`; `datetime`
  сохраняется в ISO-формате и читается обратно как `datetime`.
- Таблица создаётся в **`Init`**, а не при импорте модуля — так требует компилятор
  ([`AMX301`](../reference/diagnostics.md#amx301)).
- Данные загружаются в **`Authorized`**: в этот момент SteamID уже известен.
- `await table.get(...)` выполняется вне игрового потока — кадр сервера его не ждёт.

## Что проверяют тесты

- первый заход — «Добро пожаловать, Bob!»;
- после переподключения — «С возвращением! Визит №2, прошлый — …».
